# سَكَن سبليت (Sakan Split) 🏠💸

تطبيق ويب عصري ومتكامل لإدارة وتقسيم مصاريف الشقق والسكن المشترك بين الأصدقاء والزملاء بكل شفافية وبدون إحراج.

## المميزات الرئيسية ✨

1. **تسجيل ومشاركة المصاريف:**
   - تقسيم متساوي أو مخصص بين أفراد السكن.
   - تصنيفات متعددة (طعام، فواتير، إيجار، مشتريات، إنترنت، صيانة).
   - توثيق التاريخ والدافع والملاحظات.

2. **حسابات دقيقة وخوارزمية تصفية ذكية:**
   - معرفة فورية لمن عليه فلوس ومن له فلوس.
   - خوارزمية ذكية لاقتراح أقل عدد ممكن من التحويلات المالية لتصفية جميع الديون.
   - زر "تسوية الآن" لتسجيل السداد بضغطة زر.

3. **إدارة أفراد السكن:**
   - إضافة وحذف وتعديل أعضاء السكن.
   - كود دعوة فريد للانضمام للسكن.
   - تتبع رصيد كل ساكن وإجمالي ما دفعه وما استهلكه.

4. **تكامل Supabase & وضع غير متصل (Offline Mode):**
   - يدعم الاتصال المباشر بقاعدة بيانات Supabase عند تزويد المتغيرات.
   - يعمل تلقائياً وبكفاءة كاملة عبر التخزين المحلي `LocalStorage` عند عدم وجود اتصال أو قبل إدخال المفاتيح.

5. **واجهة عربية أنيقة تدعم RTL:**
   - مبنية بـ Next.js App Router و Tailwind CSS v4.

---

## متطلبات التشغيل والبدء 🚀

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد متغيرات البيئة (اختياري للربط مع Supabase):
قم بنسخ ملف `.env.local.example` إلى `.env.local` وأضف مفاتيح مشروعك:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### 3. تشغيل وضع التطوير:
```bash
npm run dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000)

### 4. بناء المشروع للإنتاج:
```bash
npm run build
npm run start
```
